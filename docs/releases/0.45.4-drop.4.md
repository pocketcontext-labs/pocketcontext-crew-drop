# Crew for Drop 0.45.4-drop.4

Run the guest executable with `--drop-manifest` to print its version, runtime interfaces, required services and minimum supported resources in the `drop.manifest/v1` format. The command exits before guest startup and works with an empty home directory. Drop can inspect this release before a customer deploys it.

Deployments use the same storage layout and startup command as 0.45.4-drop.3. Verify the release executable against the accompanying checksum. See the [guest guide](../../drop/README.md).
