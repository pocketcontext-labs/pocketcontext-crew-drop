# Crew for Drop 0.45.4-drop.6

Crew Settings now offers owner-selected recovery copies for each Drop workspace. Both local and funded copies include records and immutable attachment originals. Funded copies survive loss of the volume. Restore validates the selected copy and resets hosted sessions. The guest supports sizing from one CPU quarter and 256 MiB of memory.

Upgrade the executable on its existing volume. Keep a stopped pre-upgrade backup and the prior executable for rollback. Upgrading leaves existing data and sign-in in place. See [the guest guide](../../drop/README.md) for backup scope and the recovery process.
