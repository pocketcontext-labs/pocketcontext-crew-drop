# Crew for Drop 0.45.4-drop.3

The guest can run without AWS credentials. On a Drop node with host services (Drop 0.4.0 and NibRunner with `hostServices`), NibRunner gives the guest a loopback S3 endpoint, and the node's proxy signs each request again with the app's own session.

- **Host S3 endpoint.** When `AWS_ENDPOINT_URL_S3` is set to plain HTTP on a loopback address and both placeholder keys are present, Litestream, attachments and enrollment use that endpoint with path-style addressing. The guest then waits for no workload identity token. Without the variable, the guest uses workload identity as in 0.45.4-drop.2.
- Everything in [0.45.4-drop.2](0.45.4-drop.2.md) is unchanged: the 10 s sync interval, confirmed sync on suspend and terminate, and the history settings.

Install the release executable and check its SHA-256 against the accompanying checksum file. The app identity, storage paths and replica layout are unchanged. See the [guest guide](../../drop/README.md).
