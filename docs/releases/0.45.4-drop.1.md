# Crew for Drop 0.45.4-drop.1

The Linux/amd64 guest accepts lifecycle calls on the port selected by NibRunner and authenticates them with its per-app bearer. Suspend reopens ingress after draining and flushing, including when it times out. The guest sends sign-in codes through NibRunner’s host mailbox binding.

Install the release executable and check its SHA-256 against the accompanying checksum file. Configure the app as a Crew app on Drop 0.2.0 with a hook-capable NibRunner host. The existing app identity, SQLite and attachment storage paths are preserved. See the [guest guide](../../drop/README.md) for configuration.
